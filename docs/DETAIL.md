# KOOK bot

Daily configuration is now in **Account menu → Settings → KOOK**. Existing Token, workspace, allowlists and model configuration are preserved.

Connect KOOK private messages and allowed channels to DSH for text and image conversations, and send workspace images back to the current chat. Image understanding requires a model with image input support.

Use this page to inspect the version, enable or disable the plugin, or uninstall it. Saving KOOK settings stops active tasks and reconnects the bot.

Installation and usage: https://github.com/SherryXXX8043/dsh-kook#readme
