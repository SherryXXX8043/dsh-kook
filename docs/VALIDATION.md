## rc5.8 同条 @机器人与图片

本轮明确支持在同一条 KOOK 图片卡片中实际 @机器人账号、附图并填写问题，无需预先发送 `/image`。同条没有正文、仅提及机器人并附图也可处理，按上下文查看，缺少具体问题时默认简要描述图片。现有 `type: 10` 卡片的 section 文字和 container 图片沿用原解析链路，不增加设置；`mentionWakeup` 默认开启、自动转发默认关闭，白名单和会话隔离保持不变。

同条图片自带的问题优先于旧的待接图问题；仅在本次图片没有正文时采用尚有效的待接图问题。同条附图消息中的 `/image <问题>` 直接处理当前图片，不再等待下一张。分成两次发送仍应先发 `@机器人 /image <问题>` 或前缀命令，再由同一账号在同一频道于两分钟内发图。私聊可直接发图与问题，无需 @。

实际故障调查已有证据：未进入 DSH 的图片卡片使用 `(rol)…(rol)` 提及同名“Nemo”角色，而后续独立文字使用 `(met)…(met)` 提及机器人账号。角色提及不触发符合权限设计；该记录不证明正确机器人账号提及的每种图片组合均已通过。

设置页“图片使用”折叠区和中英文文案增加同条、两步及私聊说明，并强调选择机器人账号而非同名角色。README 同步更新重试方法。

- 完整回归 **172 项通过**，包括新增 10 项同条图文测试；构建、语法和差异检查通过。覆盖真实形状的 section KMarkdown + container 图片经 transport、bridge、受限下载和模拟附件保存后一次提交文字与图片，裸 @图片默认描述、旧问题不覆盖新正文、inline `/image`、开关、白名单、角色拒绝及两步隔离。
- 独立只读复核没有发现阻断问题。针对最终设置与图文逻辑又运行 23 项相关测试，全部通过。
- 只读平台记录已观察到正确 `(met)` 机器人提及、图片与正文同条发送后机器人正确识别图片文字。安装 rc5.8 后，用户进一步确认“同一条消息中正确 @机器人＋仅图片、不带正文”识别成功。真实验证覆盖这两个组合，不扩展为所有格式与权限组合均通过。
- 测试过程没有替用户调用模型或补发消息；上述平台端到端操作由用户完成。设置页面视觉仍未由自动化验收。原有历史验证记录保留如下。


## rc5.7 活跃会话共享兼容

用户真实频道 @测试已触发插件，但旧适配器对 `ctx.agents.get(id)` 返回任意活跃 Agent 都报 `SESSION_OWNED`；本地界面打开原映射会话也会遇到该错误。修复为仅对已存在的 KOOK 路由恢复路径，验证活跃 Agent 身份、工作目录及预设一致、非子代理后借用原 Agent。借用不挂载预设、不覆盖模型、不取得销毁权限；插件卸载及 `/new` 仅释放本插件绑定。明确 `/stop` 可停止该共享对话的任务。

- 完整自动化回归 **162 项通过**，语法与差异检查通过；新增 19 项借用回归覆盖外部生命周期、参数验证、预设/目录拒绝、恢复竞争、登记失败、失效身份、重复路由隔离、最终提交检查及图片工具。
- 仅 `SessionAlreadyOwnedError` 且已出现匹配活跃 Agent 时允许恢复竞争回退；其他持久化或 setup 异常保留。不会创建替代会话或重投已提交消息。
- 借用句柄每次使用前检查当前 Agent 对象；异步读取后提交、事件回传和图片发布再次核对。已失效借用映射下一条消息重新获取。损坏映射将一个 Session 指向多个 KOOK 路由时拒绝复用，避免覆盖接收目标。
- 本地界面与 KOOK 使用同一条历史，借用期间的助手回复可能回传对应 KOOK 聊天；冷恢复仍按原模型策略，活跃借用保留当前模型。
- 真实 KOOK @事件能够到达插件已由用户错误截图确认，但此修复后的平台端到端回复仍待用户复测。测试没有调用真实模型、销毁界面 Agent 或替用户发送消息。

## rc5.6 @机器人唤醒

本轮增加 `mentionWakeup` 配置，默认 `true`。设置 → KOOK → 访问权限中新增“@机器人唤醒”，沿用现有主题样式、双语文案和同一套配置保存操作。自动转发提示同时说明关闭后仍可使用命令前缀或已启用的提及唤醒；关闭提及唤醒不会关闭已开启的自动转发。

预期频道行为：白名单用户在白名单频道实际选择并提及当前机器人后可直接发送正文；按当前机器人身份识别，不按昵称或普通“@名称”文字匹配，不将 @所有人和 @角色作为直接提及。仅提及而没有正文返回帮助。私聊触发、频道白名单及按用户隔离会话继续沿用。

图片仍使用显式两分钟接图流程：可以发送 `@机器人 /image <问题>` 后再发图，不承诺自然语言自动等待下一张图片，也不扩展纯文字卡片的处理范围。

- 完整回归 **143 项通过，0 失败、0 跳过**；客户端构建、全部模块语法检查通过。新增提及回归 14 项、开关保存回归 1 项、官方 SDK 本地 WebSocket 提及元数据验证 1 项。
- 覆盖：真实事件结构经 transport → bridge → followup，提及当前 ID、正文清理、其他提及保留、伪造正文标签/昵称、all/here/roles、错误字段、未知机器人身份、bot/self 过滤、开关默认与禁用、前缀/自动转发兼容、白名单、两用户会话隔离、裸 @帮助、控制命令、一次性接图及排队图片取消。

- 独立代码与使用流程审查没有发现阻断性缺陷。新增 UI 使用既有布局和主题，不新增在线状态展示。

## 模型策略

本地版有意让创建或恢复使用当前插件选择，可能覆盖曾在 DSH UI 单独修改的 KOOK 会话选择。显式模型没有 reasoningEffort 时清除旧 effort，使用该模型默认。模型选择事件本身不检查供应商可用性；首次真实模型调用才会验证相关凭据与服务。

不使用版本豁免，不放宽到未知未来 DSH 版本，不修改 DSH 安装文件。
